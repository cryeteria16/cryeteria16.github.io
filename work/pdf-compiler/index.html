Job Documents
Quotes, vendor quotes, approval emails and reports, filed in Drive by job. Folders are created by the app.
Main Drive folder
All job folders are created inside one main folder of your Google Drive.
  1. In Google Drive, create a folder (for example VW Job Documents), or pick an existing one.
  2. Open it, then copy the link from the address bar (or just the long ID at its end).
  3. Paste it here and press Save. This is needed only once.
Duplicate files
Finds files saved more than once in the same job (same content, any name). The oldest copy stays; the extra copies go to the Duplicates folder in Admin Documentation. Nothing is deleted: empty that folder yourself.
