# ibadhasan.com

Ibad Hasan's personal site and The Lair, served by GitHub Pages.

| Path | What it is |
|---|---|
| `index.html` | Public site — Visuals & Archive |
| `lair.html` | The Lair OS (signed-in area) |
| `admin.html` | Admin Studio |
| `showcase.html` | AGFS breakdown report tool (admin only) |
| `css/`, `js/` | Styles and scripts for each page (`js/firebase-config.js` is shared) |
| `icons/` | App and browser icons |
| `sw.js`, `manifest.json` | Install-as-app support |
| `firebase.json`, `firestore.rules` | Firebase settings and database rules |

The backend that the Lair talks to (`vault.ibadhasan.com`) lives in a separate private repository. Everything in this repo is public.
