# ibadhasan.com

Ibad Hasan's personal site and The Lair, served by GitHub Pages.

| Path | What it is |
|---|---|
| `index.html` | Public site — Visuals & Archive |
| `lair.html` | The Lair, at ibadhasan.com/lair: private, owner only (Dashboard, Vault, Theater) |
| `admin.html` | Settings, at ibadhasan.com/admin (owner only) |
| `css/`, `js/` | Styles and scripts for each page |
| `icons/` | App and browser icons |
| `sw.js`, `manifest.json` | Install-as-app support |

The Lair talks to two private backends: the always-on helper at `api.ibadhasan.com` (sign-in, notes, watchlist, settings, homepage data; repo `lair-edge`) and the home PC at `vault.ibadhasan.com` (Vault files and movies). Everything in this repo is public, and none of it is secret.
