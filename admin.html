iPhone backup Shortcut

A one-tap Shortcut that sends every photo taken since its last run to your PC. It uses its own key that can only add photos: it can't see, download or delete anything. Your PC needs to be on.

How to make the Shortcut (5 minutes, once)
  1. Create a key above and copy it.
  2. Open the Shortcuts app, tap +, name it Back up to Lair.
  3. Add Text and paste your key into it. Long-press it, Rename to Key.
  4. Add Get Contents of URL: https://vault.ibadhasan.com/api/photos/backup/since. Show More, Headers: Authorization = Bearer then the Key variable.
  5. Add Get Dates from Input (input: Contents of URL).
  6. Add Find Photos with the filter Date Taken is after the Dates variable, sorted by Date Taken.
  7. Add Repeat with Each (Photos). Inside it:
    1. Format Date: Repeat Item's Date Taken, format ISO 8601, include time.
    2. Get Contents of URL: https://vault.ibadhasan.com/api/photos/backup/upload?name= then Repeat Item's Name, then &taken= then the Formatted Date. Method POST, header Authorization = Bearer + Key, Request Body File = Repeat Item.
  8. After the repeat, add Get Contents of URL: https://vault.ibadhasan.com/api/photos/backup/finish, method POST, same header.
  9. Add Show Notification: "Backed up to The Lair". Then tap the share button, Add to Home Screen.

Each photo goes to Photos › iPhone › its month, at full quality. Ones already there are skipped. Videos over about 95 MB can't go through the Shortcut: use Back up in The Lair for those. Stuck on a step? Ask Claude and it will walk you through it.
